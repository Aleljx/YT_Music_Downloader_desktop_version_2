# YouTube Music Downloader

Настольное приложение для поиска и скачивания музыки с YouTube и YouTube Music. Интерфейс построен на PyQt6; приложение использует `yt-dlp` для получения аудио и `FFmpeg` для конвертации в MP3.

## Интерфейс

![Главное окно YouTube Music Downloader](docs/images/app-main.png)

## Возможности

- Поиск треков на YouTube и YouTube Music.
- Получение названия, исполнителя и обложки по ссылке.
- Предпрослушивание найденного трека.
- Скачивание отдельного трека или очереди в MP3 с максимальным качеством исходного аудио.
- Добавление метаданных и обложки в MP3-файл.
- Настройка папки загрузки, языка интерфейса (русский, украинский, английский), темы и акцентного цвета.
- История загрузок и справка внутри приложения.
- Автоматическая установка и обновление `yt-dlp` и `FFmpeg`.

## Запуск из исходного кода

Требуется Windows и Python 3. Утилиты `yt-dlp` и `FFmpeg` приложение загружает при первом запуске и затем обновляет автоматически.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Если PowerShell запрещает активацию виртуального окружения, можно установить зависимости напрямую:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Сборка приложения

Для сборки установщика необходимы Python, Inno Setup 6 и установленные зависимости проекта. Из корня репозитория выполните:

```powershell
.\.venv\Scripts\Activate.ps1
.\build.bat
```

Скрипт соберёт приложение PyInstaller и, если Inno Setup 6 установлен, создаст установщик в `dist\installer\`. Если Inno Setup не найден, сначала установите его, затем повторно запустите `build.bat`.

## Данные приложения

Настройки, история и загруженные исполняемые файлы хранятся отдельно от программы:

```text
%LOCALAPPDATA%\YouTubeMusicDownloader\
```

При удалении установщик предлагает также удалить эти данные. Скачанная музыка при этом не затрагивается.

## Структура проекта

- `main.py` — запуск приложения.
- `app/` — интерфейс, загрузка, настройки, справка, темы и локализация.
- `requirements.txt` — Python-зависимости.
- `build.bat`, `YouTubeMusicDownloader.spec`, `installer.iss` — сборка приложения и установщика.

## Используемые инструменты

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [FFmpeg](https://ffmpeg.org/)
- PyQt6, Pillow и Mutagen

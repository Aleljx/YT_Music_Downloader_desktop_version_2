# YouTube Music Downloader

[Українська](README.md) | [English](README.en.md) | [Русский](README.ru.md)

Настільний застосунок для пошуку та завантаження музики з YouTube і YouTube Music. Інтерфейс створено на PyQt6; для отримання аудіо застосунок використовує `yt-dlp`, а для конвертації в MP3 — `FFmpeg`.

## Інтерфейс

![Головне вікно YouTube Music Downloader](docs/images/app-main.png)

## Можливості

- Пошук треків на YouTube і YouTube Music.
- Отримання назви, виконавця й обкладинки за посиланням.
- Попереднє прослуховування знайденого треку.
- Завантаження окремих треків або черги у MP3 з найвищою якістю доступного аудіо.
- Додавання метаданих і обкладинки до MP3-файлу.
- Налаштування теки для завантажень, мови інтерфейсу (українська, англійська, російська), теми та кольору акценту.
- Історія завантажень і довідка в застосунку.
- Автоматичне встановлення й оновлення `yt-dlp` та `FFmpeg`.

## Запуск із вихідного коду

Потрібні Windows і Python 3. Під час першого запуску застосунок завантажить `yt-dlp` і `FFmpeg`, а надалі оновлюватиме їх автоматично.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Якщо PowerShell забороняє активацію віртуального середовища, встановіть залежності без активації:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Збирання застосунку

Для збирання інсталятора потрібні Python, Inno Setup 6 і встановлені залежності проєкту. У корені репозиторію виконайте:

```powershell
.\.venv\Scripts\Activate.ps1
.\build.bat
```

Скрипт збере застосунок за допомогою PyInstaller і, якщо встановлено Inno Setup 6, створить інсталятор у `dist\installer\`. Якщо Inno Setup не знайдено, встановіть його та запустіть `build.bat` ще раз.

## Дані застосунку

Налаштування, історія та завантажені виконувані файли зберігаються окремо від програми:

```text
%LOCALAPPDATA%\YouTubeMusicDownloader\
```

Під час видалення інсталятор також пропонує видалити ці дані. Завантажена музика не видаляється.

## Структура проєкту

- `main.py` — запуск застосунку.
- `app/` — інтерфейс, завантаження, налаштування, довідка, теми й локалізація.
- `requirements.txt` — залежності Python.
- `build.bat`, `YouTubeMusicDownloader.spec`, `installer.iss` — файли для збирання застосунку й інсталятора.

## Використані інструменти

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [FFmpeg](https://ffmpeg.org/)
- PyQt6, Pillow і Mutagen
